# 180 Days of Python Backend

A day-by-day Python learning journey focused on building backend programming
fundamentals through small examples and exercises.

## Current Progress

### Day 1: Classes and Dunder Methods

Day 1 introduces:

- Class state and instance state
- Python classes and object attributes
- Dunder methods and operator overloading
- `__init__`, `__str__`, `__len__`, `__add__`, and `__eq__`
- A dictionary-like `UserRepository` implementation

day_1/

small runnable examples.

## Requirements

- Python 3.8 or newer

No external packages are required.

## Getting Started

Clone the repository and move into the project directory:

```bash
git clone https://github.com/Vansh856/180_DAYS_OF_PYTHON_BACKEND.git
cd 180_DAYS_OF_PYTHON_BACKEND
```

Run an example from the repository root:

```bash
python day_1\Class_State_vs_Instance_State.py
python day_1\DAY1_TASK.py
```

To run an individual dunder-method example:

```bash
python "day_1\dundler_1(__init__).py"
python "day_1\dundler_2(__str__).py"
python "day_1\dundler_3(__len__).py"
python "day_1\dundler_4(__add__).py"
python "day_1\dundler_5(__eq__).py"
```

On macOS or Linux, replace the Windows path separator (`\`) with `/`.

## Learning Notes

Start with the Markdown notes, then run the matching Python examples and
modify the classes to observe how their behavior changes.
